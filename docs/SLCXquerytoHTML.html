Music of the Waters

Number of songs by origin location, sorted by frequency

This is a simple bar graph which calculates the total number of sea songs present from each country in Smith’s book. This graph is also sorted in such a way that the country with the largest number of present songs is listed first and then the rest are placed in descending order beneath that. It is important to remember however, that this graph does not reflect the total number of songs from any country and is only reflective of the number of songs that Smith managed to collect for this book.

This graph is generated with Xquery that I will breakdown below

Pt. 1.)

let $doc := doc("MusicOfTheWaters.xml")

let $songs := $doc//songTitle[@originLocation]

let $locs := distinct-values($songs/@originLocation)


doc(...) loads the XML file into memory.

$doc//songTitle[@originLocation] uses an XPath expression to find every (songTitle) element anywhere in the document that has an originLocation attribute. The // means "search at any depth."

distinct-values(...) pulls out the unique location names from those attributes. So if "Ireland" appears 10 times, it only appears once in $locs.

Pt. 2.)

let $data :=

for $loc in $locs

let $c := count($songs[@originLocation = $loc])

order by $c descending

return map { "location": $loc, "count": $c }


This part counts how many songs have that location, then sorts them from most to fewest (order by $c descending). It then packages each result into a map (which is basically like a key-value dictionary) with a "location" and "count" field.

Pt. 3.)

The next part (code not shown for brevity sake) is setting up the constants for the bar graph’s SVG. Using variables here means I can tweak the chart's appearance in one place without hunting through the SVG code. The total SVG dimensions are then calculated from these variables:

$svg-w = label area + bar area + right padding

$svg-h = number of locations × (bar height + gap)

(text .../), ← location label on the left

(rect .../), ← the colored bar

(text .../) ← the count number on the right


For each location in the sorted data it draws three SVG elements:

(text) (left)The location name, right-aligned before the bar

(rect)The blue bar, whose width is proportional to the count vs. the maximum count

(text) (right)The raw count number displayed after the bar

The bar width formula (count / max) * chart-width makes sure that the location with the most songs always gets a full-width bar, and all others are scaled relative to it.

So basically, the flow is - XML file, extract songs, count by location, sort, draw SVG bars, then wrap in HTML
